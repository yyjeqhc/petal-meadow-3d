# 风之花境

一款以风、花瓣与山野为主题的电影化网页 3D 互动体验，使用 Three.js 与程序化着色器实现。

## 运行

```bash
npm install
npm run dev
```

打开终端显示的本地地址即可游玩。生产构建使用：

```bash
npm run build
npm run preview
```

## 操作

- 鼠标 / 触摸：按住画面并移动，引导花瓣群飞行
- 键盘：`WASD` 或方向键
- 天气按钮：切换晴风、漫云、太阳雨与雨后薄雾
- 停止操作：镜头会逐渐拉近，并启用景深

场景包含程序化起伏地形、实例化草浪、动态云影、低地雾、体积感云簇、沿途生长的花朵、粒子雨和自适应电影化后期。
