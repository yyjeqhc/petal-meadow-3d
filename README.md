# Petal Meadow 3D

一个原创的电影化网页 3D 花野原型：操纵一群漂浮花瓣掠过起伏草坡，草浪随风起伏，云影扫过地面，所经之处会逐渐开花，并在晴岚、薄雾、细雨与金色晚风之间缓慢切换。

## 运行

Windows / PowerShell：

```powershell
cd E:\git\petal-meadow-3d
npm install
npm run dev
```

生产构建：

```powershell
npm run build
npm run preview
```

## 操作

- `WASD` / 方向键：控制花瓣群在草海上飘行
- `Shift`：顺风加速
- `T`：手动切换天气（天气也会自动轮转）
- 停止移动约 1 秒：镜头自动拉近，同时加强浅景深 / bokeh

## 画面系统

- 程序化起伏地形与 9k+ 草叶风场，形成连续“风吹麦浪”效果
- 实时移动的程序化云影覆盖地面
- 程序化天空体积云采样，无图片纹理、模型或第三方美术资产
- 地表低雾 + 远景指数雾
- 动态天气：晴岚、风起、薄雾、细雨、金色晚风
- 细雨粒子、动态太阳与曝光
- 花瓣群使用 instancing；沿路径生成的花朵会持续生长并保留在当前游玩会话
- ACES Filmic tone mapping、轻度色彩分级、暗角和电影上下遮幅
- 停驻时启用近景跟随和景深后处理

## 性能

渲染像素比上限为 `1.35`，草叶与花瓣/花朵尽量使用批量几何或 instancing。程序化体积云是当前最主要的 GPU 开销；如需面向轻薄本，可进一步降低云层采样步数或草叶数量。
