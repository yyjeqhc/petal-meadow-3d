# Windborne Meadow

一个完全程序化生成的网页 3D 草原游戏原型。体验借鉴“风推动一群花瓣穿过自然景观”的抽象意象，但不使用或复制任何现成游戏资产、关卡或品牌内容。

## 视觉与交互

- 起伏程序化地形与 GPU Instanced 草浪
- 由风场驱动的草叶摆动
- 程序化云影扫过草地
- 可操控的花瓣群；移动路径会逐渐长出野花
- Ray-marched 体积云、低空雾带、动态薄雨
- 天气、风力、阳光与雾浓度连续变化
- 停下后镜头自动拉近，并逐步开启景深
- ACES 电影色调映射、轻微 Bloom、暗角和颗粒

## 运行

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
npm run preview
```

## 操作

- `W` / 按住鼠标：前行
- `A` / `D`：转向
- 鼠标横向位置：行进时辅助转向
- `Shift`：疾风加速
- `S`：制动
- 松开操作并停下：镜头拉近，开启景深观察模式
